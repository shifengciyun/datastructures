# 自习室预约管理系统 - 视频拍摄脚本

> 本脚本为使用说明视频的完整口播稿和操作步骤，可直接照着念并操作。

---

## 视频信息

- **时长**：约 5~8 分钟
- **格式**：屏幕录制 + 旁白解说
- **工具**：终端窗口 + 录屏软件（OBS / Windows 自带录屏）

---

## 第一段：开场介绍（约30秒）

### 口播稿

> 大家好，今天给大家演示一下我用 C 语言开发的自习室预约管理系统。
>
> 这个系统实现了自习室座位的在线预约、签到签退、信用分管理等功能，全部代码只有一个 C 文件，大约 650 行。
>
> 下面我来演示一下系统的完整使用流程。

### 操作

- 画面停在终端界面，显示程序启动画面

---

## 第二段：编译与启动（约30秒）

### 口播稿

> 首先我们来编译这个程序。使用 gcc 编译器，加上 `-Wall -Wextra -std=c99` 参数，编译 `main.c` 文件。
>
> 编译完成后，运行生成的 `study_room` 程序。
>
> 可以看到系统提示正在加载数据，因为是第一次运行，还没有数据文件，所以会有提示，这是正常的。

### 操作

```bash
# 输入编译命令
gcc -o study_room main.c -Wall -Wextra -std=c99

# 运行程序
./study_room
```

## 第三段：管理员初始化自习室（约1分钟）

### 口播稿

> 在学生使用之前，需要管理员先初始化自习室。
>
> 我们在主菜单选择"管理员"，然后选择"初始化自习室"。
>
> 输入自习室编号，我这里输入 1。
>
> 输入座位数量，我输入 10 个。
>
> 可以看到系统提示已初始化 10 个座位。
>
> 管理员还可以用"查看所有座位"来查看当前座位状态，现在所有座位都是空闲状态。
>
> 初始化完成后，选择返回主菜单。

### 操作

```
选择: 3（管理员）
选择: 1（初始化自习室）
自习室号: 1
座位数量: 10
选择: 2（查看所有座位）→ 展示所有空闲座位
选择: 4（返回）
```

## 第七段：签到操作（约45秒）

### 口播稿

> 预约成功后，到了预约时间需要签到。

## 第九段：取消预约演示（约1分钟）

### 口播稿

> 我再演示一下取消预约的功能。
>
> 先预约一个新座位，选择座位 5，时间从 18 点到 20 点。
>
> 预约成功后，选择"取消预约"，输入预约号。
>
> 系统提示预约已取消。
>
> 注意，如果取消时间距离预约开始不足 30 分钟，会被扣除 2 信用分。提前 30 分钟以上取消不扣分。

### 操作

```
选择: 2（预约座位）
座位号: 5
开始时间: 18 0
结束时间: 20 0
→ 预约成功
选择: 3（取消预约）
预约号: 2
→ 显示"预约 2 已取消"
```

## 第十段：信用分说明（约30秒）

### 口播稿

> 信用分是系统的重要机制，用来约束学生的行为。
>
> 新注册的学生有 100 信用分。
>
> 正常签退加 1 分，超时未签到扣 5 分，临近取消扣 2 分。
>
> 当信用分低于 10 分时，就无法再预约座位了。
>
> 所以大家要养成按时签到签退的好习惯。

### 操作

- 画面停在学生菜单，无需操作

## 拍摄注意事项

1. **终端字体**：调大一些（16号以上），保证录屏清晰
2. **操作节奏**：每步操作后停顿 1~2 秒，给观众反应时间
3. **输入错误**：如果输错了，可以直接重新输入，后期可以剪掉
4. **提前练习**：正式拍摄前先完整走一遍流程，熟悉操作
5. **分段录制**：可以按段落分开录制，后期拼接
6. **录屏设置**：分辨率 1920x1080，帧率 30fps 即可
