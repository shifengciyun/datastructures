# 自习室预约管理系统 - 简化版开发指南

## 项目概述

使用纯C语言实现自习室预约管理系统，采用单文件架构，去除统计分析模块，最大化简化开发工作量。

## 开发环境

- **语言**：C语言（C99标准）
- **编译器**：GCC 或 MSVC
- **依赖**：无第三方库，仅标准库

## 文件结构

```
study_room_system/
├── main.c          # 所有代码集中在此文件
├── data.txt        # 数据持久化文件
└── Makefile        # 编译脚本（可选）
```

## 数据结构设计

### 核心结构体

```c
// 学生
typedef struct {
    int id;
    char name[50];
    char password[50];
    int creditScore;    // 信用分，初始100
} Student;

// 座位
typedef struct {
    int id;
    int roomId;
    int status;         // 0=空闲, 1=已预约, 2=使用中
    int studentId;      // 当前使用者
} Seat;

// 预约记录
typedef struct {
    int id;
    int studentId;
    int seatId;
    time_t startTime;
    time_t endTime;
    int status;         // 0=待签到, 1=使用中, 2=已完成, 3=已取消, 4=超时取消
} Reservation;

// 链表节点
typedef struct Node {
    void *data;
    struct Node *next;
} Node;

// 哈希表
typedef struct {
    Node **buckets;
    int size;
    int count;
} HashTable;

// 队列
typedef struct {
    Node *front;
    Node *rear;
} Queue;
```

## 命名规范

- **函数名**：大驼峰 `CreateReservation`
- **变量名**：小驼峰 `studentId`
- **常量/宏**：全大写 `MAX_STUDENTS`
- **类型名**：大驼峰 `StudentHashTable`

## 关键算法

### 1. BKDR哈希函数
```c
unsigned int BKDRHash(const char *str) {
    unsigned int seed = 131;
    unsigned int hash = 0;
    while (*str) {
        hash = hash * seed + (*str++);
    }
    return hash % HASH_SIZE;
}
```

### 2. 冲突检测
```c
// 检查时间段是否重叠
int IsTimeOverlap(time_t s1, time_t e1, time_t s2, time_t e2) {
    return s1 < e2 && s2 < e1;
}
```

### 3. 信用分规则
- 预约成功：不变
- 正常签退：+1
- 超时未签到：-5
- 主动取消（提前30分钟）：不变
- 主动取消（不足30分钟）：-2

## 注意事项

1. **单文件优势**：编译简单、无链接问题、便于提交
2. **内存管理**：每个 malloc 必须有 free
3. **字符串安全**：使用 strncpy 而非 strcpy
4. **输入校验**：检查 scanf 返回值
5. **数据备份**：退出前自动保存
