# 自习室预约管理系统 - 使用说明

---

## 一、系统简介

本系统是一个基于命令行的自习室座位预约管理系统，支持学生预约座位、签到签退，以及管理员管理自习室等功能。

### 功能概览

| 角色 | 功能 |
|------|------|
| 学生 | 注册、登录、查看座位、预约、取消、签到、签退、查看记录 |
| 管理员 | 初始化自习室、查看所有座位、重置系统 |

### 信用分规则

| 行为 | 信用分变化 |
|------|-----------|
| 注册 | 初始 100 分 |
| 正常签退 | +1 |
| 超时未签到 | -5 |
| 临近取消（<30分钟） | -2 |
| 提前取消（≥30分钟） | 不变 |
| 信用分 < 10 | 禁止预约 |

## 二、环境准备

### 编译

```bash
gcc -o study_room main.c -Wall -Wextra -std=c99
```

### 运行

```bash
./study_room
```

首次运行时没有 `data.txt` 文件，系统会提示加载失败，这是正常的。

## 三、操作流程

### 3.1 管理员初始化自习室

首次使用时，需要管理员先初始化自习室和座位。

```
===== 自习室预约系统 =====
1. 注册
2. 登录
3. 管理员
4. 保存数据
5. 退出
请选择: 3

===== 管理员菜单 =====
1. 初始化自习室
2. 查看所有座位
3. 重置系统
4. 返回
请选择: 1

输入自习室号: 1
输入座位数量: 10
已初始化 10 个座位 (自习室 1)
```

**说明**：
- 自习室号：任意正整数，用于区分不同自习室
- 座位数量：1~100 之间
- 初始化会清空之前的座位和预约记录

### 3.2 学生注册

```
===== 自习室预约系统 =====
请选择: 1

输入用户名: zhangsan
输入密码: 123456
注册成功！学号: 1
```

**说明**：
- 用户名不能重复
- 密码无长度限制
- 注册后自动获得 100 信用分

### 3.3 学生登录

```
===== 自习室预约系统 =====
请选择: 2

输入用户名: zhangsan
输入密码: 123456
登录成功！欢迎 zhangsan (信用分: 100)
```

登录成功后进入学生菜单。

### 3.4 查看可用座位

```
===== 学生菜单 =====
1. 查看可用座位
2. 预约座位
3. 取消预约
4. 签到
5. 签退
6. 我的预约
7. 退出登录
请选择: 1

=== 可用座位 ===
座位号   自习室   状态
------------------------
1        1        空闲
2        1        空闲
3        1        空闲
...
------------------------
空闲座位: 10/10
```

**说明**：
- 状态为"空闲"的座位可以预约
- 状态为"已预约"或"使用中"的座位不可预约

### 3.5 预约座位

```
请选择: 2

输入座位号: 3
输入开始时间 (小时 分钟): 14 0
输入结束时间 (小时 分钟): 16 30
预约成功！预约号: 1
座位: 3 | 时间: 2026-06-16 14:00 ~ 2026-06-16 16:30
```

**说明**：
- 座位号必须是空闲状态
- 时间格式为"小时 分钟"，用空格分隔
- 结束时间必须晚于开始时间
- 系统会自动检测时间冲突
- 信用分低于 10 分时无法预约

### 3.6 取消预约

```
请选择: 3

输入预约号: 1
预约 1 已取消
```

**取消规则**：
- 只能取消自己的预约
- 只能取消"待签到"状态的预约
- 提前 30 分钟以上取消：不扣分
- 不足 30 分钟取消：扣 2 分

**提示**：可以先用"我的预约"查看预约号。

### 3.7 签到

```
请选择: 4

输入预约号: 1
签到成功！座位 3
```

**签到规则**：
- 只能签到自己的预约
- 只能签到"待签到"状态的预约
- 必须在预约开始时间前后 15 分钟内签到
- 超时未签到：预约自动取消，扣 5 分

### 3.8 签退

```
请选择: 5

输入预约号: 1
签退成功！信用分+1
```

**签退规则**：
- 只能签退自己的预约
- 只能签退"使用中"状态的预约（即已签到的）
- 签退后信用分 +1
- 座位恢复为空闲状态

### 3.9 查看我的预约

```
请选择: 6

=== 我的预约记录 ===
预约号   座位   开始时间             结束时间             状态
------------------------------------------------------------
1        3      2026-06-16 14:00     2026-06-16 16:30     待签到
2        5      2026-06-16 10:00     2026-06-16 12:00     已完成
3        2      2026-06-16 09:00     2026-06-16 11:00     超时取消
```

**预约状态说明**：
- 待签到：已预约，等待签到
- 使用中：已签到，正在使用
- 已完成：正常签退
- 已取消：用户主动取消
- 超时取消：未按时签到，系统自动取消

### 3.10 退出登录

```
请选择: 7
已退出登录
```

退出后返回主菜单，可以切换其他账号登录。

### 3.11 保存数据

```
===== 自习室预约系统 =====
请选择: 4
数据保存成功
```

**说明**：
- 数据保存到当前目录的 `data.txt` 文件
- 退出程序时会自动保存
- 建议操作过程中定期手动保存

### 3.12 退出程序

```
===== 自习室预约系统 =====
请选择: 5
感谢使用，再见！
```

退出时会自动保存数据并释放内存。

## 五、常见问题

### Q1: 提示"信用分过低"无法预约怎么办？

信用分低于 10 分时会被限制预约。可以通过正常签退获得信用分奖励（每次 +1），或联系管理员重置系统。

### Q2: 签到时提示"签到超时"是什么意思？

预约开始时间超过 15 分钟后仍未签到，系统会自动取消预约并扣 5 分。请在预约时间开始后尽快签到。

### Q3: 取消预约会扣分吗？

- 提前 30 分钟以上取消：不扣分
- 不足 30 分钟取消：扣 2 分

建议确定不去时尽早取消，避免扣分。

### Q4: 数据文件在哪里？

数据保存在程序同目录下的 `data.txt` 文件中。可以手动备份此文件以防止数据丢失。

### Q5: 如何修改系统参数？

在 `main.c` 文件顶部的常量定义区域可以修改：

```c
#define INITIAL_CREDIT 100       // 初始信用分
#define CREDIT_PENALTY_LATE 5    // 超时扣分
#define CANCEL_THRESHOLD_MIN 30  // 取消免扣分阈值（分钟）
#define CHECKIN_TIMEOUT_MIN 15   // 签到超时时间（分钟）
```

修改后需要重新编译。

### Q6: 可以同时预约多个座位吗？

可以。同一个学生可以同时预约多个不同座位，但不能预约同一座位的重叠时间段。

## 六、完整操作示例

以下是一个完整的使用流程示例：

```
1. 运行程序
2. 选择 3（管理员）→ 选择 1（初始化自习室）→ 输入自习室号 1，座位数 5
3. 选择 4（返回）
4. 选择 1（注册）→ 用户名: student1，密码: 123
5. 选择 2（登录）→ 用户名: student1，密码: 123
6. 选择 1（查看座位）→ 看到 5 个空闲座位
7. 选择 2（预约）→ 座位号 1，开始 14:0，结束 16:0
8. 选择 6（我的预约）→ 看到预约号 1，状态待签到
9. 选择 4（签到）→ 输入预约号 1
10. 选择 5（签退）→ 输入预约号 1
11. 选择 6（我的预约）→ 看到状态已完成，信用分 +1
12. 选择 7（退出登录）
13. 选择 5（退出）
```
